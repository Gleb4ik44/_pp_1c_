# Тест-кейсы: смоук-тестирование

Формат: ID, объект, метод, предусловия, шаги, ожидаемый результат. Фактический результат и ссылка на баг-репорт (если есть расхождение) фиксируются в колонке «Статус» по мере прогона.

Относится к `test-plan-smoke.md`.

## TC-11 — Смоук-тест: запуск базы и открытие основных разделов

- **Объект:** Вся конфигурация
- **Метод:** Смоук
- **Предусловия:** База развернута, пользователь авторизован.
- **Шаги:** Последовательно открыть разделы «Закупки», «Продажи», «НСИ», «Казначейство», «Персонал», «Аналитика».
- **Ожидаемый результат:** Все разделы открываются без ошибок, списки объектов формируются, интерфейс отвечает на действия пользователя.
- **Статус:** пройден
