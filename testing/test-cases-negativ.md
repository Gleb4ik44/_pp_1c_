# Тест-кейсы: негативное тестирование

Формат: ID, объект, метод, предусловия, шаги, ожидаемый результат. Фактический результат и ссылка на баг-репорт (если есть расхождение) фиксируются в колонке «Статус» по мере прогона.

Относится к `test-plan-negativ.md`.

## TC-04 — Расходная накладная: попытка отгрузки сверх остатка

- **Объект:** Документ «Расходная накладная», процедура `ОбработкаПроведения`
- **Метод:** Негативное, граничное
- **Предусловия:** Остаток товара на складе — известное конечное число (например, 10 шт.).
- **Шаги:** Создать расходную накладную, указать количество больше фактического остатка (например, 20 шт. при остатке 10), попытаться провести.
- **Ожидаемый результат:** Отказ в проведении (`Отказ = Истина`), пользователю выводится сообщение вида «Не хватает товара "<товар>" на складе "<склад>" в количестве <N> <ед.изм.>», остаток в регистре не изменяется.
- **Статус:** пройден — поведение соответствует ожидаемому, логика проверки остатков подтверждена

## TC-07 — Загрузка курсов валют: недоступность сервиса

- **Объект:** Общий модуль «РаботаСВалютами»
- **Метод:** Негативное
- **Предусловия:** Сеть отключена или сервис недоступен.
- **Шаги:** Запустить процедуру загрузки курсов валют при отсутствии сетевого доступа.
- **Ожидаемый результат:** Исключение перехватывается, пользователю выводится сообщение «Произошла сетевая ошибка!», документ не формируется, аварийного завершения сеанса не происходит.
- **Статус:** пройден

## TC-08 — Получение цены номенклатуры: цена не установлена на дату

- **Объект:** Общий модуль «Вспомогательный», функция `ПолучитьЦенуНоменклатуры`
- **Метод:** Негативное, граничное
- **Предусловия:** По товару нет ни одной записи в регистре сведений «ЦеныНоменклатуры» на запрашиваемую дату и вид цены.
- **Шаги:** Вызвать функцию с товаром, для которого цена не установлена.
- **Ожидаемый результат:** Функция возвращает 0, исключение не возникает.
- **Статус:** пройден

## TC-10 — Отчет «Остатки товаров на складах»: отображение при увеличенном масштабе экрана

- **Объект:** Отчет «ОстаткиТоваровНаСкладах», форма отчета
- **Метод:** Негативное, UI
- **Предусловия:** Масштабирование экрана Windows установлено выше 100% (например, 175–200%, актуально для демонстрационной среды на Retina-дисплее).
- **Шаги:** Сформировать отчет с суммовыми значениями от шести знаков.
- **Ожидаемый результат:** Колонки «Цена» и «Сумма» отображают значения полностью.
- **Фактический результат:** При масштабе экрана выше 100% колонки «Цена» и «Сумма» отображаются как «####» — значения не помещаются, автоматический расчет ширины колонок платформой работает некорректно. При масштабе 100% отчет формируется корректно. Причина — известная особенность работы платформы 1С с нецелым масштабированием экрана Windows, не связана с логикой самого отчета.
- **Статус:** дефект найден, см. `bug-report.md` (BUG-01)
