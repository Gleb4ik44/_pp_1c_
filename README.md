# Автоматизация складского учета магазина электроники (1С:Предприятие 8.3)

ВКР по теме "Автоматизация складского учета". Направление 09.03.03 "Прикладная информатика", профиль "Корпоративные информационные системы".

## Что тут лежит

- `Румянцев Г.В. 70200358.dt` - выгрузка базы с преддипломной практики. Восстанавливается в Конфигураторе: Администрирование -> Загрузить информационную базу.
- Конфигурация, выгруженная в текстовые файлы (XML и модули на .bsl). Раньше тут просто лежал бинарный дамп базы, но по нему нельзя было посмотреть код - только скачать файл целиком. Поэтому дальше конфигурация выгружается в файлы, и по мере доработок сюда будут добавляться остальные объекты.
- `test-plan.md`, `test-cases.md`, `bug-report.md` - тест-план, тест-кейсы и баг-репорт по подсистеме складского учета.

## Код

Модули документов и справочников лежат в файлах .bsl, например `Documents/ИмяДокумента/Ext/ObjectModule.bsl`. Открываются прямо на GitHub, без скачивания.

## Как развернуть

1. Ставим 1С:Предприятие 8.3, учебная версия (online.1c.ru).
2. Создаем пустую информационную базу в Конфигураторе.
3. Администрирование -> Загрузить информационную базу -> указываем `Румянцев Г.В. 70200358.dt`.
